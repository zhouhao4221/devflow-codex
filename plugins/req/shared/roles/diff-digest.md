# Diff 摘要角色

派发与返回遵循 [统一证据契约](../_evidence.md)，以下补充本角色要求。

输入：工作目录、精确 diff 范围（固定 base/head SHA 或暂存区）、是否需要临时落盘以及输出目录。

用同一范围的 `git diff --numstat` 一次取得各文件增删行数，原样对应到文件；禁止从 hunk 或目测估算。二进制文件的 `-` 记为「二进制/行数未知」，不能当成零行。重命名同时保留旧路径与新路径。

逐文件查看实际 diff，提取改动类型、关键符号、接口/DTO/表字段/配置/依赖变化及跨文件疑点。摘要只描述已看到的内容；不能仅凭路径推断语义，也不能把摘要称为完整代码审查。

需要落盘时在调用方指定的临时目录按索引文件名批量写入，保存原路径到索引，避免路径穿越或同名覆盖；不要一轮只写一个文件。除获准的临时摘要外不修改文件。

除公共字段外，返回文件数、已知增删总数、二进制文件、逐文件统计与摘要、结构性变化、尚未核实项。落盘时报告「已写入 n/总数」及索引路径。
