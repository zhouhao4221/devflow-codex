# PM 维护约定

PM 是需求数据的只读消费者，从 PRD、需求文档和 Git 记录生成报告，不能修改需求状态。没有需求数据时说明范围，可基于 Git 数据汇报。统计与结论要有实际来源，不把提交数量直接等同于工作量。

报告默认在对话中输出；用户要求保存、使用 `--save` 或执行 `pm:export` 时写入文件，已有保存授权不重复确认。默认保存路径位于 `docs/reports/`，尊重用户指定路径。只读需求数据不妨碍按授权保存报告。维护各命令和 `report-generator` 时核对这些边界，不能仅依赖本文件约束安装后的技能。

不将 Claude 版的固定模型字段移入 Codex skill 或 UI 元数据。
