# UAT 维护约定

流程文档位于 `docs/uat/flows/`，报告和截图位于 `docs/uat/reports/` 及对应截图目录。按操作意图定位界面，testid/aria-label 可作为加速信息，不要求预写选择器。

保留 PASS、带说明的 PASS、FAIL、SKIP 区别。只有实际执行的步骤才能记录为通过；上报 issue 要有失败场景和证据，并遵循用户授权。

执行测试时保留原始预期与实际差异；更新 `最后执行` 元数据和生成报告，不等于授权改写场景预期。用户要求维护流程时可以修订，但需保留原始发现，不能以修改预期替代缺陷记录。相关边界应在 `run` 和 `uat-executor` 中保持一致。

初始化使用实际安装技能的位置解析模板和资源，不假设目标项目包含本仓库的 `plugins/uat/` 目录；复制技能时核对依赖是否仍可访问，并保留项目已有定制。
