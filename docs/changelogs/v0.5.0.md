# DevFlow Codex v0.5.0

本版本为命令增加按任务复杂度选择执行模型的路由，并补充命令设计规范。

## 命令与子任务路由

- 64 个命令按 `executionTier` 分级：economy 38 个、standard 9 个、primary 17 个；`req:release` 使用经济档处理规则化发版准备。
- 子任务按复杂度请求 Luna、Terra 或 Sol；需求分析、设计、跨文件决策和最终验收保留在主会话。
- 遵守 Codex 当前参数能力、用户模型偏好和运行时限制；不支持模型覆盖时说明原因并回退，不声称已测量费用或节省比例。

## 命令设计规范

- 以用户可感知结果定义入口、输入、事实源、授权范围、失败续接和验收证据。
- 保持命令包装精简，流程判断由 SKILL.md 和按需加载的共享规则承载；配置、项目数据和插件业务边界继续以 Codex 现有规范为准。
- release 的写入性质与推理成本分开判断，实际提交、推送、tag 和平台 Release 仍须由主会话按授权执行。
