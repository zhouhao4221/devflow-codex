# DevFlow Codex v0.4.1

本版本修正技能中的授权与完成边界，精简需求开发流程，并减少无关技能和资料的加载。

## 工作流修复

- “不用确认”“自动修”只影响已授权任务的交互，不再自动扩展为提交、推送或创建 PR；纯 PR 审查完成后交付报告，不追加评论、Approved 或合并确认。
- 继续开发时保留已有实现和用户无关改动，仅在实际编辑或分支切换冲突时暂停；普通开发完成相关验证后再报告结果。
- QUICK 统一复用 dev 的实施与验证流程，归档后再执行已授权提交推送；提交时保留调用方传入的需求编号和归档路径。
- 创建、编辑需求及提交代码时复用完整输入和已有授权，去掉固定访谈、重复确认及无条件提交类型菜单。
- 提交确认 marker 仅表达 DevFlow 偏好，不再声称能控制 Codex 原生权限弹框；Issue 操作不从 marker 时间戳推断授权。

## 技能精简

- 收紧 API 字段映射、快速修复与代码影响分析的触发范围；仅修改 Vue 文案或样式不会因为 API import 加载字段映射技能。
- dev 管理统一流程，dev-guide 只保留后端、前端和全栈的专项参考；需求定义成文细节移入按需读取的参考文件。
- specs 按变更模块和接口筛选读取；修正本次涉及的 QUICK、需求编辑及开发指导中的旧缓存逻辑。
- 同步命令参数提示、技能元数据和绑定，保留 Codex marketplace 与兼容导出布局。
