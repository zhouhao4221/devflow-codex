# DevFlow Codex v0.7.0

本版本将 Req 的交互验证升级为能力感知自动走查，并统一 UAT 对 Chrome、内置浏览器和 Computer Use 的运行时选择与模型规则。

## 插件版本

| 插件 | 版本 |
|------|------|
| API | 0.5.0 |
| Diag | 0.3.0 |
| PM | 0.6.0 |
| Req | 3.29.0 |
| UAT | 1.5.0 |

## 主要变更

- `req:test` 对自动化未覆盖的测试点探测当前 UI 控制能力，可执行时自动走查，否则生成手动验证清单。
- 根据目标和会话状态选择 Chrome、内置浏览器或 Computer Use，不再通过环境变量或客户端名称推断能力。
- UI 操作、视觉断言和最终验收保持 `primary` 主会话模型；机械测试命令与日志摘要仍可按既有规则降档。
- 新增 `--skip-walkthrough`，并让 `--failed` 只重跑失败或未完成的走查项。
- UAT 在浏览器不支持脚本求值时明确记录 Console Error 未采集，避免误报为无错误。
