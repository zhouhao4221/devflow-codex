# DevFlow Codex v0.8.3

> 发布日期：2026-09-23
> 版本范围：v0.8.1..v0.8.3

本版本将默认子任务执行模型迁移至 GPT-6，并完善技能维护规范。v0.8.2 尚未正式发布，因此本次同时包含其需求评审与代码审查拆分改动。

## 插件版本

| 插件 | 版本 |
|------|------|
| API | 0.6.2 |
| Diag | 0.3.2 |
| PM | 0.6.2 |
| RD | 4.0.3 |
| UAT | 1.5.2 |

5 个插件均包含共享模型路由更新，各提升一个补丁版本。

## 本次更新

- 经济档默认使用 `gpt-6-luna` / `low`，标准档默认使用 `gpt-6-sol` / `medium`，深入执行可按需使用 Sol / `high`。
- 保留用户选择的主会话模型负责方案与验收；派发前检查运行时实际支持的模型及推理强度，不可用时按现有规则回退。
- 更新共享委派规则、README 和全部插件的生成路由。主会话已为 Sol 时，仅对值得独立并行的常规任务另派 Sol 子代理。
- 完善根目录及 RD、PM、Diag、UAT 的 AGENTS.md：明确作者源与生成文件、技能触发和辅助加载、授权边界及按变更选择验证。
- 增加 79 个技能的规范检查报告，区分静态检查结果与工作流正文中尚待修复的问题。

## 包含的 v0.8.2 改动

- 拆分需求评审与代码审查（`5450b82`）：新增 `/rd:req-review`；`/rd:review` 专注 PR 代码审查及按评论修改；`/rd:pr` 聚焦创建、状态、只读评论和合并。
- 优化非逻辑改动的审查路由，避免文档、样式、lock 或生成物误触发重型审查。
- 移除旧版配置兼容规则（`c79f040`），统一使用 `.devflow/` 与项目内需求目录。

## 已知限制

本版本未修复检查报告中列出的 Diag 缺失脚本与只读承诺冲突、UAT 自动修改测试预期及初始化路径、辅助技能加载契约、PM 无参数导出问题。维护规范更新不代表这些工作流正文已修复。详见 [技能检查报告](../reports/2026-09-23-skill-audit.md)。
