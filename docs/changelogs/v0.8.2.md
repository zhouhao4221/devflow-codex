# DevFlow Codex v0.8.2

本版本拆分需求评审、代码审查与 PR 平台操作，并优化非逻辑代码变更的审查路由。

## 主要变更

- 新增 `/rd:req-review`，负责 REQ 提审、AI 预审和评审结果记录；`/rd:review` 改为专职 PR 代码审查与按人工评论修改代码。
- `/rd:pr` 聚焦创建、状态、只读评论和合并；同步更新自然语言路由、执行档位、模板和迁移提示。
- 代码审查区分逻辑代码、展示层与非代码文件，避免文档、样式、lock 或生成物变更误触发重型审查。
- 清理旧版 DevFlow 配置兼容规则，统一使用 `.devflow/` 配置与项目内需求目录。
