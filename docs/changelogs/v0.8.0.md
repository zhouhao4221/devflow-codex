# DevFlow Codex v0.8.0

本版本将研发工作流插件由 `req` 迁移为 `rd`，补全 QUICK 生命周期与 PR 入口，并为 API 插件加入实际的 Swagger/OpenAPI 解析器。

| UAT | 1.5.0 |

## 主要变更

- **升级操作**：安装 `rd` 并停用旧 `req` 插件；命令前缀改为 `/rd:`。PR 创建、状态、审查、评论与合并统一使用 `/rd:pr`。项目需求文档与 `.devflow/` 配置仍使用原路径；操作说明见 [README](../../README.md)。
- QUICK 改为由 `new-quick → dev → test → done` 依次处理文档、开发、测试和完成状态。需求列表实时读取文档，目录守卫检查状态与生命周期；升级为 REQ 的 QUICK 保留原状态，归档在 `superseded/`，不计入已完成。
- API 插件新增 Swagger/OpenAPI 解析器与中、英、韩文教程，支持按配置的数据源查看摘要、搜索及接口详情。解析器已修复 `allOf` 同级字段、操作级参数覆盖和 Swagger 2 引用请求体的处理。
- 对照 Claude 平行实现的基准记录在 [来源版本与适配说明](../changes/2026-09-16-claude-sync.md)：`525bf60bfbfcca07218ba0ca9e6f51f13c7d534b`，提交时间 `2026-09-16T19:10:32+09:30`。两仓继续保留各自的平台实现。
