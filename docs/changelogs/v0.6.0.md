# DevFlow Codex v0.6.0

本版本为 Req 的 PR 审查流程接入 Codex 原生代码审查能力，并通过固定提交范围与隔离工作树确保审查结果只覆盖目标 PR。

## 插件版本

| 插件 | 版本 |
|------|------|
| API | 0.5.0 |
| Diag | 0.3.0 |
| PM | 0.6.0 |
| Req | 3.28.0 |
| UAT | 1.4.0 |

## 主要变更

- `req:review-pr` 在大型 PR 场景优先调用 Codex 原生 `codex exec review`，小型 PR 仍由当前会话直接审查。
- 原生审查适配器固定 base/head 提交，并在临时 detached worktree 中执行，避免切换或污染用户工作树。
- 原生能力不可用或执行失败时仅回退一次到按模块或行为拆分的 Codex 子代理审查，不修改用户配置。
- 统一原生审查与内联审查的阻塞规则：正确性、安全、数据和兼容性问题按实际后果决定是否阻塞。
