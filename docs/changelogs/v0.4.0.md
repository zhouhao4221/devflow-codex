# DevFlow Codex v0.4.0

本版本完善 Codex marketplace 分发、原生子代理协作和测试验收流程。包含自旧版标签以来的 marketplace 迁移，以及本轮工作流、共享资源和兼容导出更新。

## 主要变化

- 以 `SKILL.md` 为作者源，生成 Codex plugin manifests、command 包装及 marketplace 索引；分发 79 个 skills、64 个 commands。
- 将重复工作流附录集中到共享资源，按需读取；明确 devflow-codex 与 devflow-claude 是同一维护者的平行实现。
- 按 Codex 原生能力派发有界子任务，按需继承上下文；实现与对应测试归同一单元，约束共享目录写入，支持原代理续接。
- 统一子任务状态、覆盖范围和验证证据；复用结果时核对当前内容，识别过期 PASS、遗漏审查和范围外改动。
- `test-new` 支持按文件生成 UT 及无写入的 dry-run；完善有序验证、readonly 边界和固定 base/head 的 PR 审查。
- 重做分层与扁平兼容导出，携带引用资源和模板，保护已有输出及源仓库；分层导出默认写入独立目录。
- CI 增加兼容导出回归和生成产物一致性检查，移除旧 npm 发布任务；项目主分支配置与实际 `master` 对齐。

## 升级说明

使用 Codex marketplace 安装或更新插件。旧 npm CLI 分发不再是本仓库的发布渠道。兼容导出使用 `scripts/setup-claude.sh` 或 `scripts/setup-opencode.sh`，输出到空目录或本导出器拥有的目录；不要将另一个维护中的仓库作为导出目标。

行为验证不代表所有客户端或真实项目的性能结论；本版本不宣称已测得 token 节约率。
